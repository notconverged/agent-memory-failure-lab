# Claude-Mem and Basic Memory trial protocol

External services are not installed by the repository test suite. Run each in a
separate temporary repository, separate configuration/data directory, and with
the same `ledger-rounding-evolution-v1` snapshots. Record exact version, commit,
install source, permissions, network use, and test date.

## Claude-Mem

Observe hooks, worker lifecycle, SQLite schema, progressive disclosure, capture
gaps, semantic-boundary behavior, conflict/pivot handling, context cost, and
recovery after worker or database failure.

## Basic Memory

Observe MCP/Skills surfaces, file-first inspectability, manual correction,
branch/repository scope, pivot handling, context cost, and recovery from invalid
or partially written files.

## Shared record

For every phase record installation minutes, captured substance, missed events,
memory state before/after the pivot, injected context/tokens, first Agent action,
test outcome, user correction effort, and failure recovery steps. These are
system-level product comparisons; do not attribute causal superiority to a
single storage or retrieval mechanism.
